Where does "caving to the user" live? Probing and steering sycophancy in Qwen2.5

Sycophancy, where a model tells users what they want to hear, is one of the most visible failures of RLHF-trained assistants. OpenAI rolled back a GPT-4o update in April 2025 because of it. This project measures it in Qwen2.5-1.5B-Instruct (replicated on 0.5B), finds linear directions in the residual stream that predict when the model will capitulate, and tests whether subtracting a contrastive steering vector reduces sycophancy without damaging capability.

Code, data pipeline and full write-up: github.com/rishikeshn-eng/sycophancy-probe-steer

Model:

1 · Baseline sycophancy

Opinion sycophancy (Anthropic model-written-evals): the user states a view in a bio, and we check whether the model picks the matching option. Pushback sycophancy (TruthfulQA + are_you_sure MC): the model answers, the user pushes back and names a specific other option, and we check whether the model switches to the user's answer. When the model was right, switching is capitulation. When it was wrong and the user names the correct option, switching is healthy updating. Plain "are you sure?" follows the meg-tong protocol: the user only expresses doubt and names no alternative.

2 · Linear probes: can we read "will capitulate" from the residual stream?

Logistic-regression probes on every layer's residual stream, with 5 seeds (mean ± sd shaded). Three read positions: the decision token, the end of the user's pushback, and the end of the model's first answer, before the pushback has been seen. The last is a forward-looking signal of how firmly the model holds its answer.

Generalisation: leave-one-dataset-out (train on the other sources, test on the held-out one) and cross-kind transfer (opinion ↔ pushback).

3 · Steering: layer × coefficient sweep

Difference-of-means vectors (CAA, Rimsky et al. 2024) are built from train-split contrast pairs and added at one layer with strength α × (mean residual norm). Negative α steers away from sycophancy. The sweep is measured on a held-out test subset.

Method notes & limitations

  • Scores are next-token letter probabilities after a fixed assistant prefix The answer is (. Steering is applied at every position. During pushback evaluation the turn-1 answer is the unsteered model's.
  • Small models (0.5B/1.5B) on one laptop; results may not transfer to frontier models.
  • Opinion-sycophancy items with two options are partly confounded with letter bias. See the README for the per-letter control.
  • meg-tong feedback (essay-feedback sycophancy) was not evaluated, because it needs long-form judged generations.
